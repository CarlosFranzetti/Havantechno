## 2026-11-21 16:03 EST (21:03 UTC) — C2's second pass received (source files read by curl)

Section 12 of C2-open-emulations.md (the file is now 293 lines), everything fetched from raw.githubusercontent.com; github.com and api.github.com refused, so C2 read only files whose paths it knew. Not checked by the coordinator.

Starting points as C2 states them. TB-303: the diode-ladder filter and output network in midilab/jc303 (SPDX AGPL-3.0-or-later, copyright 2026 David Lowenfels): a topology-preserving ladder with a tanh per diode, two Newton steps a sample, no oversampling; calibrated to its author's own SPICE netlists (0.26 dB rms on resonance), no comparison with hardware stated; C2 judges it a better filter and output path than the Open303 filter the app uses and a few days' port, with Open303 kept for the oscillator, envelopes, accent and slide. Model D: CA-72's light model (crates/ca72/src/light.rs; GPL-3.0-or-later from the workspace manifest, no SPDX line in the files): the only part that can run in a browser, since CA-72's README says its circuit model does not run in real time on most computers; the light model is fitted to the circuit model's behaviour; about 2 % of a fast core a voice by C2's division of the README's figures. Juno: KR-106's filter, cutoff tables and envelope (GPL-3.0 at repository level, no "or later", no file headers), with a firmware-level cutoff and envelope model and a table measured from one real voice card; chorus from Holters and Parker with BBDDelay (BSD-3-Clause). TR-909: keep the present source; eh2k's numbers as a bench, numbers only (eh2k states "the firmware as a whole is for personal use only"). TR-808: no single file; chowdsp_wdf (BSD-3-Clause, confirmed) with the DAFx-14 equations; the snare resonators in WaveDigitalFilters (GPL-3.0 text, no "or later"). Also: Surge's diode ladder lives in sst-filters (GPL-3.0-or-later per file); MoogLadders has a newer Newton-solved ladder with antiderivative antialiasing under the Unlicense, a candidate to replace the ImprovedMoog model; a1k0n/303 measured a real x0xb0x and has a JavaScript file, with no licence.

Licence notes for the strategy: "GPL-3.0" without "or later" (KR-106, WaveDigitalFilters) is compatible with an AGPL-3.0-or-later app only in its GPL-3.0 form; code with no licence statement (WDR-8's README line aside, a1k0n/303) cannot be copied, though measured numbers can be cited.
