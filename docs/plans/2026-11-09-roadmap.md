# Roadmap: deconstruction and recreation (set 2026-11-08 ET)

The owner's instruction, 8 November 2026 (ET): when a track is loaded for analysis, work out what elements it uses; for a synth sound, approximate it to the DAW's own synth recreations (and say whether it is mono or poly, FM or analog, with or without reverb, and whether the effects sound built in or outboard), load those recreations onto tracks for each isolated sound, or suggest an existing plugin; for drums, load an 808 or 909 recreation when the sound is plainly one, guess when it is not, and use samples through the DAW's own sampler when the sound is a sample. Load and save projects; when an audio file is imported for deconstruction, save it as a project right after analysis, and always allow A/B between the original and the recreation. Work in batches, with research crews and plugin-development crews, everything logged.

Scope note from the owner: the app is for the owner and a few friends, never commercial. The coordinator's standing position: the recreations ship as synthesis and as samples whose licences allow redistribution (public domain, CC0, or a free licence that permits it), and ported code comes from GPL/AGPL/MIT projects with attribution in `THIRD_PARTY.md`; sample sources with unclear licences are catalogued for the owner's own machine but not committed.

## What a well-rounded app still needs (beyond the batches)

Audio tracks with waveform editing; a mixer view; MIDI input and a piano roll for the melodic tracks; automation lanes; a plugin host (CLAP or VST3 through the Electron shell's native side, or Web Audio Modules in the browser); presets per device; undo across everything; project templates; export of stems; a real true-peak limiter (AudioWorklet); latency compensation; keyboard shortcuts and accessibility passes; packaging for macOS and Windows; a help page per device.

## Order of work from here

Research crews for batches 1, 2, 3 and 5 run first (Crate Crew, Box Crew, Lab Crew), each with transcripts and a report. Then batch 1 is built and scored, then batch 2. Batch 3 and 4 follow once the sampler and the drum machines exist, since the classifier needs recreations to point at.
