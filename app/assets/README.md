# app/assets

Material that ships with the app under its own terms, not under the repository's AGPL licence. Each folder is listed in `THIRD_PARTY.md`.

- `tr909-robroy/`: Rob Roy Recordings' free TR-909 sample set (1995), 160 mono 16-bit 44.1 kHz WAV files and `TR909SET.TXT`, kept whole and unmodified as its text file asks. Free to copy; not to be distributed for profit. A commercial release must leave this folder out.

ROM images and samples without a stated permission to redistribute do not go here or anywhere else in the repository. On a developer's machine they live in the git-ignored `local/` folder; in the app they are loaded from files the user supplies.
